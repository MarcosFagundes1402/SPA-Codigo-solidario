# Código Solidário

Projeto desenvolvido como atividade prática da faculdade.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- localStorage
- Git e GitHub

## Funcionalidades

- Navegação em SPA
- Página inicial
- Página de projetos
- Formulário de cadastro
- Validação de formulário
- Armazenamento de dados no localStorage
- Interface responsiva

## Estrutura do projeto

- html/
- css/
- imagens/
- js/

## Execução

Abra o projeto através de um servidor local, como o Live Server do VS Code.
