# Código Solidário

Projeto desenvolvido como atividade prática da faculdade.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- localStorage
- Git e GitHub

## Funcionalidades

- Navegação em SPA
- Página inicial
- Página de projetos
- Formulário de cadastro
- Validação de formulário
- Armazenamento de dados no localStorage
- Interface responsiva

## Estrutura do projeto

- html/
- css/
- imagens/
- js/

## Organização do JavaScript

O código JavaScript foi dividido em módulos para separar responsabilidades:

- `app.js`: controla a navegação, eventos e integração da aplicação
- `templates.js`: contém os templates das telas
- `validation.js`: concentra a validação do formulário
- `storage.js`: gerencia a persistência dos dados no localStorage

## Acessibilidade

Foram aplicadas melhorias de acessibilidade, como:

- uso de textos alternativos em imagens
- associação entre `label` e campos do formulário
- estados visuais de foco
- feedback para campos válidos e inválidos
- mensagens dinâmicas com `aria-live="polite"`

## Execução

Abra o projeto através de um servidor local, como o Live Server do VS Code.
